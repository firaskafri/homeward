# Homeward UI State Matrix

Each listed surface requires loading, content, empty, validation, recoverable
error, permission-degraded, and dismissal behavior where applicable.

## Setup

- Setup status menu: Finish Setup, Quit
- Onboarding: Schedule, Work Apps, Closing, Permissions, Ready
- Optional preview: choose app, first quit, relaunch wait, second quit, result,
  needs attention, timeout/cancel

## Daily operation

- Menu: Work available, Winding down, Closing, Work closed, Work extended
- Overview: current state, next transition, app count, close mode, warnings
- Schedule: all day modes, same-day/overnight, validation, copy
- Work Apps: loading, results, no matches, selected, unavailable/reselection
- Closing: Gentle, Firm warning, Firm countdown, force paused, force failed
- General: every notification and Start-at-Login status

## Interruptions

- Warning notification
- Closing panel with one or multiple apps
- Blocked-launch explanation
- Gentle attention
- Note capture
- Next-window note review
- Configuration recovery

## Required variants

- Light and dark appearance
- Increased contrast and Differentiate Without Color
- Reduced motion and transparency
- Largest supported text size
- Keyboard and VoiceOver
- 200% and 400% Zoom
- Single and multiple displays, Spaces, full-screen apps, hidden/notched menu
  bar
- Long localized strings, long app names, missing app icons
