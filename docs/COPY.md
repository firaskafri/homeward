# Homeward Copy

Use calm, literal language.

Preferred state copy:

- Work available
- Winding down
- Closing work apps
- Work is closed
- Work extended
- Available Monday at 9:00 AM
- No work window scheduled

Preferred actions:

- End Work Now…
- Change Today Only…
- Show App
- Leave Open This Time
- Stop Force Quit
- Resume Firm Closing…
- Make All Work Apps Available for 10 Minutes…
- Save a Thought…
- Start Homeward
- Start & Close Work Apps…

Avoid access-denied language, failure or shame language, streaks, distraction
labels, scores, and claims that Homeward prevents an application from starting.

Use an ellipsis only when an action opens another choice or confirmation.
“Today” and “tomorrow” are used only when calendar-correct; otherwise show the
localized weekday, date, and time.
